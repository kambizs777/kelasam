kelasam - پروژه نسخه اندروید (فایل نصبی APK)

این پوشه یک پروژه کامل Capacitor است. برنامه داخل پوشه app قرار دارد (همان کد نسخه موبایل) و داخل یک برنامه اندرویدی واقعی بسته‌بندی می‌شود.
اطلاعات در حافظه داخلی برنامه روی گوشی در فایل kelasam/class-data.json ذخیره می‌شود (علاوه بر حافظه مرورگر داخلی برنامه)؛
پس با بستن برنامه، خاموش شدن گوشی یا پاک شدن کش چیزی از بین نمی‌رود.

روش ۱ (ساده‌ترین، بدون نصب هیچ چیز روی کامپیوتر): ساخت APK با GitHub
 1) در github.com یک حساب رایگان بسازید و یک مخزن (Repository) جدید و خالی بسازید.
 2) محتویات همین پوشه را (همه چیز، از جمله پوشه مخفی .github) داخل مخزن آپلود کنید
    (Add file ← Upload files؛ یا با git push).
 3) به تب Actions بروید ← «Build kelasam APK» ← Run workflow. حدود ۵ تا ۱۰ دقیقه صبر کنید.
 4) پایین صفحه اجرای تمام‌شده، بخش Artifacts، فایل kelasam-apk را دانلود و از حالت زیپ خارج کنید؛ app-debug.apk همان فایل نصبی است.

روش ۲: ساخت با Android Studio
 1) Android Studio را نصب کنید (با JDK 17).
 2) در این پوشه:  npm install   سپس   npm run sync
 3) پوشه android را با Android Studio باز کنید ← Build ← Build APK(s).

نصب روی گوشی
 - فایل app-debug.apk را به گوشی بفرستید و باز کنید. اگر پیام «نصب از منابع ناشناس» آمد، اجازه بدهید.
 - برای به‌روزرسانی در آینده، APK جدید را روی نسخه قبلی نصب کنید؛ اطلاعات پاک نمی‌شود (به شرط اینکه برنامه را حذف نکنید).
 - اگر برنامه را حذف کنید، اطلاعات داخل آن هم پاک می‌شود. قبل از حذف از منوی «پشتیبان‌گیری (فایل)» فایل بگیرید.

تغییر در برنامه
 فایل‌های داخل پوشه app را ویرایش کنید و دوباره یکی از دو روش بالا را اجرا کنید.

محدودیت‌ها: چاپ مستقیم (دکمه چاپ) در نسخه اندروید در دسترس نیست. خروجی اکسل و فایل پشتیبان از طریق منوی اشتراک‌گذاری گوشی ذخیره یا ارسال می‌شود.


--- نسخه ۲٫۲ ---
* مهم: این پروژه حالا با یک «کلید امضای ثابت» (android/app/kelasam.keystore) ساخته می‌شود. از این نسخه به بعد، هر APK جدید روی قبلی نصب (به‌روزرسانی) می‌شود و اطلاعات پاک نمی‌شود.
  فقط یک بار: نسخه‌ی قدیمی (که با کلید موقت ساخته شده بود) را پیش از نصب، از «پشتیبان‌گیری (فایل)» پشتیبان بگیرید، حذف کنید و نسخه ۲٫۲ را نصب کنید.
* فایل kelasam.keystore را نگه دارید و عمومی نکنید (مخزن گیت‌هاب را Private بگذارید). اگر گم شود، به‌روزرسانی روی نسخه‌های نصب‌شده ممکن نیست.
* دکمه‌ی بازگشت: ابتدا به صفحه‌ی قبل می‌رود و برای خروج دو بار لازم است. اگر WebView به‌خاطر کمبود حافظه از بین برود، برنامه بسته نمی‌شود و صفحه دوباره ساخته می‌شود.
* در «درباره ما» بخش «گزارش پایداری» هست؛ اگر برنامه خودبه‌خود بسته شد، متن آن را برای پشتیبانی بفرستید.
